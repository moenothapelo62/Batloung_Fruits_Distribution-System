## Capture Tips

1. Use a clean browser window at 1440 by 900 pixels for desktop screenshots.
2. Use the browser device toolbar at 375 by 812 pixels for mobile screenshots.
3. Make sure the sidebar, page title and main content are visible.
4. Avoid showing real personal information.
5. Use PNG format and keep each file below 1 MB.
6. Capture the final seeded data so screenshots match the report.
